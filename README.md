# Learn Python with AI 

Learn Python programming from scratch using AI language models like ChatGPT, Claude, or Llama.

## How to Use

1. Open your preferred AI assistant.
2. Copy the full content of `prompt_en.txt`.
3. Paste it into your initial chat prompt.
4. Follow the interactive lessons and complete the exercises step-by-step.

## Repository Structure

- `prompt_en.txt`: Full teaching prompt in English.
- `prompt_fr.txt`: Full teaching prompt in French.
- `README.md`: English documentation.
- `README.fr.md`: French documentation.
