# Learn Python with AI 

Apprenez à programmer en Python de A à Z grâce aux modèles de langage (LLMs) comme ChatGPT, Claude ou Llama.

## Comment l'utiliser ?

1. Ouvrez l'outil d'IA de votre choix.
2. Copiez l'intégralité du contenu du fichier `prompt_fr.txt`.
3. Collez-le dans votre première entrée de discussion.
4. Suivez les instructions et résolvez les exercices module par module.

## Contenu du dépôt

- `prompt_fr.txt` : Prompt pédagogique complet en français.
- `prompt_en.txt` : Prompt pédagogique complet en anglais.
- `README.md` : Documentation en anglais.
- `README.fr.md` : Documentation en français.
